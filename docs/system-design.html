ShelfClaim system design

A phone sweep streams high-resolution frames and recognized speech to a local server. Deterministic code scores capture quality, clusters OCR text into book spines, matches catalogue candidates, filters real provider offers, and assembles an evidence-linked report.

Core principle: models perceive; code decides. Unsupported identity, dimensions, and prices stay blank for review.
